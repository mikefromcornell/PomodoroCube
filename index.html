About & free hosting

PomodoroCube is plain HTML/CSS/JS — no build step, no framework, no tracking, no external requests. Publish it free on GitHub Pages:

1. Push the repo to GitHub.
2. Settings → Pages → Source: GitHub Actions.
3. The included workflow deploys the site on every push.

You can also just open index.html locally — it works offline, straight from the file system.

Preview mode: this sandboxed frame cannot save settings or register a service worker. The deployed site works normally.
